# SecureChat

Защищённый чат для **Windows (ПК)** и **Android** на .NET MAUI с собственным сервером
ASP.NET Core + SignalR и сквозным шифрованием (E2E).

Сервер пересылает только зашифрованные конверты и публичные ключи. Текст сообщений
шифруется и расшифровывается на устройствах пользователей.

## Что нового в версии 1.1

- **Меню скрепки в стиле Telegram** — панель «Фото или видео», «Файл», «Музыка»,
  «Голосовое сообщение», «Видеокружок» выезжает над кнопкой 📎 и не сжимает
  переписку (и в личных чатах, и в пространствах).
- **Удаление и очистка переписки** — удалить сообщение, удалить чат или очистить
  историю можно «для себя» или «для всех»; собеседник получает уведомление.
- **Обои для пространств** — картинка под перепиской пространства с затемнением.
- **Панель Эмодзи | Стикеры | GIF** в пространствах, «Избранное» в списке чатов,
  горизонтальная прокрутка плиток тем, плавная прокрутка переписки.
- **Лимит вложений — 150 МБ**, инлайн-видео в пузыре — до 24 МБ.
- **База данных обновлена**: локальное хранилище версии 2 (старые базы читаются),
  на сервере — индекс по паре собеседников для быстрого удаления переписки.

Полный список изменений — в [CHANGELOG.md](CHANGELOG.md).

## Безопасность

- **Идентичность устройства** — две пары ключей P-256:
  - ECDH — для согласования ключа сообщения;
  - ECDSA — для подписи сообщений и отпечатка ключа.
- **Шифрование сообщения** — одноразовый ECDH-ключ отправителя + долговременный
  ECDH-ключ получателя → HKDF-SHA256 → AES-256-GCM.
- **Подпись** — ECDSA P-256 (SHA-256) покрывает заголовок, nonce, ciphertext и tag.
  Сервер проверяет подпись перед пересылкой.
- **Пароль** — клиент отправляет не сам пароль, а PBKDF2-производную
  (`AuthSecret`); сервер хранит её хеш с индивидуальной солью (PBKDF2, 210 000 итераций).
- **Локальные данные** — история чатов шифруется AES-256-GCM ключом устройства.
  Ключи и сессия хранятся:
  - Windows — DPAPI (CurrentUser);
  - Android — AES-GCM с ключом в Android Keystore.
- **Транспорт** — в production используйте HTTPS. Локальный HTTP разрешён только
  для адресов `10.0.2.2`, `localhost`, `127.0.0.1` в debug-сборке Android.
- Сервер не хранит открытый текст и не имеет приватных ключей.

### Ограничения демонстрационной версии

- Нет Double Ratchet и полноценной forward secrecy при компрометации долговременного
  ключа получателя. Одноразовый ключ отправителя защищает прошлые сообщения от
  компрометации его эфемерных ключей.
- Доверие к ключам — TOFU (trust on first use). Отпечатки нужно сверять вручную.
- Нет переноса ключей на новое устройство и мультиустройств.
- Метаданные (кто, кому, когда) сервер видит — это свойство любой модели с relay-сервером.
- Смена пароля не отзывает уже выданные JWT-токены: действующая сессия живёт до истечения токена.
- **Push-уведомлений в фоне нет.** Уведомления приходят, пока живёт процесс
  приложения: на Android SecureChat держит wake lock и Wi-Fi lock, чтобы сеть
  SignalR не засыпала. Если система остановила процесс, уведомление не придёт —
  для полноценных push нужны FCM или UnifiedPush.
- **Рабочая конфигурация — cleartext HTTP** (`http://<IP>:5080`). Сервер
  поддерживает и HTTPS, но для Android нужно убрать LAN-адрес из
  `network_security_config.xml`, иначе соединение останется без шифрования
  транспорта (шифрование самих сообщений при этом сохраняется).
- Сервер — один процесс с SQLite: кластеризация (PostgreSQL, Redis, nginx, S3)
  в версию 1.1 не входит.
- Это учебно-демонстрационный проект, а не прошедший аудит продукт.

## Запуск сервера

```powershell
dotnet dev-certs https --trust
dotnet run --project src/SecureChat.Server --launch-profile https
```

- HTTPS: `https://localhost:5443`
- HTTP: `http://localhost:5080`
- Проверка: `http://localhost:5080/api/health`

### HTTPS для доступа по LAN

`dotnet dev-certs https --trust` выписывает сертификат только для `localhost`,
поэтому клиенты по адресy `https://<IP-компьютера>:5443` получают ошибку
«The SSL connection could not be established». Для LAN нужен сертификат с этим
адресом в SAN. Он выписывается скриптом (права администратора не требуются):

```powershell
powershell -ExecutionPolicy Bypass -File tools/New-LanTlsCertificate.ps1
```

Скрипт кладёт `lan-tls.pfx`, `lan-tls.password.txt` и `lan-tls.cer` в
`src/SecureChat.Server/App_Data/` (папка в `.gitignore`) и доверяет сертификат
текущей учётной записи. Сертификат попадает в SAN автоматически: `localhost`,
имя компьютера и все активные IPv4-адреса машины (при необходимости список
можно задать параметром `-IpAddresses 192.168.50.216`). После этого сервер
нужно перезапустить — в логе появится строка
`HTTPS-сертификат: LAN-сертификат (CN=SecureChat LAN server, до ...)`.

Другие учётные записи Windows доверяют сертификат отдельно: открыть
`lan-tls.cer` → «Установить сертификат» → «Текущий пользователь» →
«Доверенные корневые центры сертификации». На Android-устройстве пользовательский
корневой сертификат по умолчанию не доверяется, поэтому телефон либо продолжает
работать по HTTP с LAN-IP, либо требует отдельной настройки
`network_security_config.xml`.

Для доступа с Android-эмулятора (HTTP, только локальная отладка):

```powershell
dotnet run --project src/SecureChat.Server --launch-profile lan-http
```

Для доступа с физического Android-устройства запустите сервер на LAN-адресе и
укажите в приложении `http://<IP-компьютера>:5080` (или настройте HTTPS).
Не забудьте разрешить порт в брандмауэре Windows. По умолчанию Android разрешает
открытый HTTP только для `10.0.2.2`, `localhost` и `127.0.0.1`; для HTTP с
LAN-IP добавьте этот адрес в
`src/SecureChat.App/Platforms/Android/Resources/xml/network_security_config.xml`.
Для постоянной работы с физическим устройством используйте HTTPS.

База данных и ключ JWT создаются автоматически в `src/SecureChat.Server/App_Data/`.
Этот каталог единый для `dotnet run`, Debug- и Release-сборок: сервер находит
папку проекта по `SecureChat.Server.csproj`, поэтому данные и сессии не
«разъезжаются» между способами запуска. Переопределить каталог можно переменной
окружения `SECURECHAT_DATA_DIR`.
**Для production обязательно задайте свой `Jwt:Key`** через конфигурацию/переменную
окружения и используйте HTTPS.

#### Интерфейс Windows-клиента

Оформление выполнено в стиле Discord/Telegram:

* **Сайдбар слева** (272 px) — логотип, карточка профиля с аватаром и цветной
  точкой статуса, выбор статуса (Онлайн / Неактивен / Занят), поиск по чатам,
  список переписок с аватарами, временем последнего сообщения и счётчиком
  непрочитанных.
* **Шапка чата** — имя собеседника, отпечаток ключа и кнопки поиска по переписке
  (🔍), меню чата (⋮) и закрытия чата (✕).
* **Меню чата (⋮)** — выпадающее меню в стиле Telegram: «Профиль, медиа и
  закреплённые», «Обои чата», «Экспорт истории чата», «Настройки»,
  «Очистить историю» и «Удалить чат» (красным). Очистка и удаление спрашивают,
  «для всех» или «только у себя».
* **Правая панель чата** (ⓘ) — три вкладки:
  * **👤 Профиль** — аватар, имя, статус, отпечаток ключа, идентификатор,
    дата регистрации;
  * **📎 Медиа** — все изображения и файлы переписки, клик открывает вложение;
  * **📌 Закреплённые** — список закреплённых сообщений, клик прокручивает
    переписку к нужному сообщению.
* **Нижние кнопки сайдбара** — «+ Чат», контакты и «Выход».
* **Область переписки** — пузыри сообщений (свои — синие справа, чужие — тёмные
  слева) в стиле Telegram, аватар отправителя показывается только у первого
  сообщения в серии, цитата ответа, отметки «(отредактировано)», разделители по
  датам и текстовый статус доставки (Отправка / Отправлено / Доставлено /
  Прочитано) внутри пузыря.
* **Панель ввода** — кнопка скрепки, поле ввода и круглая кнопка отправки.
  Неотправленный текст сохраняется как черновик и восстанавливается при
  возвращении в чат.
* **Действия с сообщением**:
  * контекстное меню по ПКМ — Копировать, Ответить, Переслать, Реакция,
    Редактировать, Удалить, Закрепить, Открыть вложение, Быстрая реакция
    (👍 ❤️ 😂 😮);
  * свайп сообщения **вправо** — быстрый ответ на сообщение;
  * свайп сообщения **влево** — панель действий: Копировать, Переслать, Удалить.
  * двойной клик по сообщению — выбор эмодзи.
* **Реакции** — двойной клик по сообщению открывает выбор эмодзи, а в контекстном
  меню по ПКМ доступны быстрые чипы (👍 ❤️ 😂 😮). Каждый эмодзи показывается
  отдельным чипом со счётчиком, свои реакции подсвечиваются, а снять можно только
  свою — чужие не затрагиваются. Реакции синхронизируются с собеседником.
* **Вложения** — кнопка скрепки открывает меню в стиле Telegram:
  «Фото или видео» (можно выбрать сразу несколько файлов), «Файл»,
  «Музыка», «Голосовое сообщение», «Видеокружок».
  Большие фото перед отправкой пережимаются до 2560 px по длинной стороне —
  в чат уходят разумные размеры, а не многомегабайтные снимки. Загрузка идёт
  по очереди: для каждого файла показывается прогресс и кнопка отмены.
* **Просмотр вложений** — голосовые сообщения слушаются прямо в пузыре
  переписки, изображения открываются встроенным просмотрщиком, аудио —
  встроенным плеером, остальные файлы — системным приложением.
* **Видео прямо в пузыре** — видеокружки и видео-файлы (mp4 и другие video/*)
  показываются крупным встроенным плеером, как в Telegram: play/пауза и
  просмотр позиции внутри сообщения, бейдж длительности («04:47») у
  видеокружка. Пока видеофайл не скачан, показывается «Загрузка видео…»;
  загрузка начинается автоматически при открытии чата.
* **GIF** — анимированные GIF отправляются через «Прикрепить → Фото или GIF»,
  в пузыре сообщения показывается бейдж «GIF».
* **Панель Эмодзи | Стикеры | GIF (ЛС)** — по кнопке 😊 над полем ввода
  открывается вкладчатая панель, как в Telegram. Вкладка «Стикеры» — крупные
  эмодзи-глифы: тап отправляет «стикер» (Kind=Sticker), получатель видит его
  крупным глифом в сообщении — по аналогии с большими эмодзи в Telegram;
  наборы локальные, внешние CDN-сервисы не используются. Вкладка «GIF»
  показывает недавние анимации из переписки (свои и присланные, до 24 штук,
  только те, что уже загружены на устройство) — тап отправляет тот же GIF
  заново. Активная вкладка подсвечивается акцентом.
* **Архив, удаление и очистка чатов** — кнопка ⋮ у каждого чата открывает меню
  (одинаково в Windows-клиенте и на Android): архивировать / разархивировать,
  отключить звук уведомлений («🔇 Без звука»), «🧹 Удалить чат» и
  «🧽 Очистить историю». Удаление чата убирает переписку из списка, очистка
  истории оставляет чат на месте. Оба действия спрашивают, удалять
  «для всех» или «только у себя», и показывают уведомление о результате.
  Кнопка 📦 переключает просмотр архива. «Избранное» нельзя архивировать
  или удалить.
* **Поиск по сообщениям** — Enter в поле поиска сайдбара открывает глобальный
  поиск по всем чатам и архиву. Результаты показывают чат, дату и фрагмент;
  клик открывает переписку. На Android поле поиска находится над списком чатов.
* **Аккаунт** — в настройках можно сменить пароль и удалить аккаунт на сервере.
  Удаление стирает переписку, вложения, участие в пространствах и локальные данные
  устройства без возможности восстановления.
* **Профиль** — в «Настройках» задаются отображаемое имя, описание (био),
  аватар и статус. Открыть настройки можно кликом по карточке профиля в сайдбаре
  или кнопкой ⚙ в шапке чата.

#### Оформление

В «Настройках → Оформление» настраивается внешний вид главного окна:

* **Тема** — палитра всего интерфейса, выбирается плитками как в Telegram
  («Классическая» = Classic, «Синяя» = Day, «Оттенок» = Tinted,
  «Ночная синяя» = Night), кнопка «Показать все темы» открывает остальные
  палитры и «Системную»:
  * тёмные: «Классическая», «Оттенок», «Ночная синяя», «Ночная зелёная»,
    «Ночная фиолетовая»;
  * светлые: «Синяя», «Зелёная», «Фиолетовая»;
  * «Системная» — следует за темой операционной системы;
* **Акцентный цвет** — пресеты Discord, Telegram, Signal, фиолетовый, красный,
  оранжевый, а также «Как в теме»;
* **Своя палитра** — «🎨 Конструктор темы»: любой цвет интерфейса можно задать
  вручную (фон, панели, подложки, границы, основной/второстепенный/
  приглушённый текст, акцент, свои и чужие пузыри, текст чужих пузырей,
  успех/ошибка/внимание). Цвет выбирается палитрой образцов или вводится
  вручную в формате `#RRGGBB`. Изменения видны сразу во всём приложении
  (живой предпросмотр с мини-копией переписки), отдельную роль можно вернуть
  к цвету темы кнопкой «Сбросить». Подобранную палитру сохраняют как **свою
  тему** под своим именем — темы лежат в зашифрованном хранилище устройства
  (не отправляются на сервер), их можно применять, переключать и удалять;
  своя тема помнит встроенную тему-основу и восстанавливает её. Свои темы
  перечислены в «Настройках → Оформление → Своя палитра»: тап применяет тему,
  повторный тап возвращает встроенную. Выбор встроенной темы-плитки снимает
  свою тему, чтобы переключение было видно;
* **Настройки темы**:
  * **Цвет вашего имени** — как «Your name color» в Telegram: цвет имени
    ваших сообщений в пространствах и комментариях (8 пресетов + «Как в теме»);
  * **Авто-ночной режим** — ночью (20:00–07:00) светлая тема автоматически
    сменяется ночной парой («Синяя» ↔ «Ночная синяя» и т.д.), днём — обратно;
  * **Шрифт сообщений** — обычный, с засечками или моноширинный
    (влияет на текст в пузырях);
* **Обои чата** — картинка под перепиской: выбор из галереи или файла,
  превью, кнопка «Убрать» и затемняющая вуаль для читабельности;
* **Форма сообщений** — скруглённая, мягкая или прямая (как в Telegram);
* **Аватары в переписке** — показывать или скрыть аватар отправителя;
* **Время у сообщений** — показывать или скрыть часы отправки;
* **Компактный список чатов** — без превью последнего сообщения;
* **Размер текста** — маленький, обычный, крупный;
* **Плотность сообщений** — компактная, обычная, просторная;
* **Подключение** — Авто (WebSocket, при ошибке переключается на TCP), SignalR
  или TCP.

Выбор сохраняется в зашифрованном хранилище устройства и применяется сразу,
без перезапуска.

#### TCP-подключение

Кроме WebSocket (SignalR) сервер принимает прямое TCP-соединение на порту
`5444`. Клиент авторизуется JWT-токеном в первом кадре, дальше идёт обмен
такими же E2E-конвертами. Транспорт выбирается в настройках или
переключается автоматически, если WebSocket недоступен.

#### Группы, каналы, форумы и сообщества

Кнопка 👥 в сайдбаре открывает список пространств:

* **Группа** (👥) — общий чат, пишут все участники;
* **Канал** (📢) — объявления, пишут только администраторы. У канала есть
  режимы: переключатель «Подписи постов» (в ленте видно «Название канала
  через @админ») и кнопка 🔕 у поля ввода — тихий пост, без звука и
  уведомлений у подписчиков;
* **Форум** (🧵) — обсуждения в отдельных темах;
* **Сообщество** (🌐) — публичная площадка, доступна всем.

Любое пространство может быть **публичным или приватным**: тумблер
«Публичное пространство» в его настройках (у владельца и администраторов).
**Публичное** доступно всем без приглашения: в списке «Пространства»
карточка помечена «🌐 публичное», тап по ней — «Вступить» (сервер делает
участником сразу, право писать — по типу пространства). Историей владеют
только участники, поэтому общий E2E-ключ новичку автоматически передаёт
любой участник в сети — обычно за секунды; пока ключ не дошёл, чат
показывает баннер ожидания. **Приватное** нигде не светится: доступ
только по приглашению владельца или администратора.

У пространства есть роли (владелец, администратор, участник, гость) и
список участников. В настройках пространства владелец и администратор могут
пригласить нового участника по логину («Добавить участника по логину») и менять
роли, нажав на участника в списке. Сообщения пространств **так же шифруются
E2E**: при создании пространства генерируется общий ключ, который шифруется
отдельно для каждого участника его долговременным ECDH-ключом. При приглашении
нового участника клиент-администратор расшифровывает ключ и передаёт его новому
участнику «конвертом», зашифрованным его публичным ключом — сервер ключа не
видит. Сервер хранит только «конверты» и шифротексты, а каждое сообщение
подписывается ECDSA-ключом отправителя, поэтому подделать сообщение другого
участника нельзя.

При создании канала/сообщества/форума обычные участники получают роль
«только чтение» (`CanPost = false`) — писать могут только владелец и
администраторы. Владелец может выдать право публикации любому участнику в
настройках пространства («Может писать» / «Только чтение» напротив имени).
Публичные пространства видны в списке всем пользователям, вступить в них
можно только по приглашению администратора — иначе ключ расшифровки не будет
выдан.

#### Упоминания @ и комментарии к постам

**Упоминания.** В чате пространства наберите `@` — как в Telegram, над полем
ввода сразу появляется меню участников: аватар, имя и @логин; при печати список
фильтруется по префиксу логина, первая строка выделена, на Windows клавиши
↑/↓/Enter/Esc работают как в Telegram. Выбор вставляет `@username` с пробелом.
Упоминания работают и **в личных чатах**: меню предлагает контакты, в сообщении
после `@` подсвечивается любой логин. В отправленном сообщении упоминания
подсвечиваются как в Telegram: акцентным цветом с подчёркиванием (в своём
пузыре — светлым, чтобы читалось на акцентном фоне), нажатие открывает
**профиль
участника** (аватар, статус, «о себе», отпечаток ключа), откуда кнопкой
«💬 Начать чат» можно открыть личный чат. Если упомянули
вас, ответили на ваше сообщение или использовали `@all`, SecureChat
показывает уведомление (Android в фоне — системное с заголовком «Название
пространства», иначе — звук рингтона уведомлений; точечно отключается
кнопкой 🔕 в шапке пространства). Такие сообщения помечаются в ленте
плашкой «🔔 Упомянули вас / ↩ Ответ вам / 📢 Упомянули всех», а кнопка
🎯 в шапке считает их и прокручивает по кругу к следующему.
`@all` доступно только владельцу и администраторам (отдельная строка
«👥 all» в меню).
Упоминания хранятся внутри E2E-шифрованного содержимого — сервер не знает,
кого упомянули. Проверка упоминаний выполняется по списку участников: случайный
`@текст` подсветки и уведомления не даст. Работает во всех типах пространств
(группа, канал, сообщество, форум и комментарии).

**Комментарии к постам канала.** Под каждым постом канала есть кнопка
«💬 Ответить» или «💬 N комментариев» (формы учитывают русские правила: 1
комментарий, 2 комментария, 5 комментариев). Нажатие открывает отдельное
окно обсуждения: список комментаторов с аватарками и временем, поле ввода
комментария (с тем же меню @упоминаний) и превью поста сверху. Комментарии —
это обычные зашифрованные E2E-сообщения пространства с меткой поста внутри
шифрованного содержимого: сервер не знает о структуре «пост/комментарий», а
лента канала такие сообщения не показывает. Свои комментарии и комментарии
других участников может удалять владелец и администраторы (🗑 в окне
обсуждения); счётчик под постом обновляется в реальном времени.

#### Встроенный браузер

Кнопка 🌐 в сайдбаре открывает встроенный браузер на WebView с адресной
строкой, историей и кнопками «домой», «обновить», «назад», «вперёд» и
«открыть в системном браузере». Ссылки в сообщениях (включая домены без
схемы, e-mail и телефоны) кликабельны прямо в тексте и открываются в нём же;
в контекстном меню сообщения есть пункты «🔗 адрес» и «📋 Копировать
ссылку». Под сообщениями показываются превью-карточки ссылок (Open Graph,
тумблер «Превью ссылок» в настройках).

#### Профиль

Отображаемое имя, био, аватар и статус отправляются на сервер, поэтому
собеседник видит их в панели «👤 Профиль». Сервер хранит только эти публичные
данные, ключи и шифротексты — приватные ключи остаются только на устройстве.

### Android

```powershell
dotnet build src/SecureChat.App/SecureChat.App.csproj -f net9.0-android -c Release
```

APK появится в `src/SecureChat.App/bin/Release/net9.0-android/`
(файл `com.securechat.app-Signed.apk`). Установка на подключённое
устройство/эмулятор:

```powershell
adb install -r "src\SecureChat.App\bin\Release\net9.0-android\com.securechat.app-Signed.apk"
```

Release-сборка подписывается ключом из `keys/securechat-release.keystore`
(параметры — в `src/SecureChat.App/keystore.props`, пароль — в
`keys/keystore.password.txt`). Оба файла исключены из git: **сохраните их
в надёжном месте**, иначе обновления приложения будет невозможно подписать тем же
ключом. Если на устройстве уже стоит debug-сборка, её нужно удалить: подписи
не совпадают.

В Android-эмуляторе адрес сервера по умолчанию — `http://10.0.2.2:5080`
(это `localhost` компьютера). В LDPlayer этот адрес может быть недоступен —
укажите LAN-IP компьютера, например `http://192.168.50.216:5080`, и добавьте
его в `network_security_config.xml`. Для физического устройства также
используйте LAN-IP.

Чтобы проверить два пользователя, запустите приложение на ПК и в эмуляторе,
зарегистрируйте `alice` и `bob`, добавьте друг друга по имени и начните чат.
Отпечатки ключей можно сверить на экране «Сверка» в чате.

2. Дописать раздел в `CHANGELOG.md`.
3. Создать тег и запушить его:

   ```powershell
   git tag -a v1.1 -m "SecureChat 1.1"

   ```


## Медиа и вложения

Приложение поддерживает отправку и получение вложений: изображения показываются inline в переписке, а любые файлы (видео, аудио, документы) прикрепляются как файл.

### Как это работает (безопасность)
1. Клиент шифрует файл случайным одноразовым ключом AES-256-GCM. Ключ, nonce, имя файла, MIME-тип и размер передаются внутри E2E-конверта сообщения — сервер их не видит.
2. Зашифрованный файл загружается на сервер через HTTP `POST /api/media/{mediaId}` (требуется JWT-токен, получатель проверяется).
3. Сервер хранит только зашифрованный blob и metadata (отправитель, получатель, размер). Имя и содержимое файла серверу недоступны.
4. Получатель после получения конверта через SignalR загружает шифротекст файла через `GET /api/media/{mediaId}` (только отправитель и получатель могут скачать), расшифровывает ключом из конверта и сохраняет локально в зашифрованном виде.

Ограничение: размер исходного файла до **150 МБ** (до 16 МБ была прежняя версия клиента). SignalR не используется для передачи медиа-данных — только для небольших метаданных в зашифрованном конверте.

Встроенный видео-плеер в пузыре (кружки и видео-файлы) работает для роликов до **24 МБ**: инлайн-рендер идёт через data-URI в WebView и ест память пропорционально размеру файла. Более крупные видео показываются карточкой с кнопкой ▶ и открываются нативным плеером из кэш-файла (как в Telegram для больших файлов) — клиент не падает по памяти.

### Интерфейс
- **Перетаскивание файлов (Windows)** — файлы можно перетащить из Проводника
  прямо в окно приложения: они отправятся вложениями в открытый чат
  (несколько файлов за один раз — альбомом). Подписью при перетаскивании
  показывается «Отправить как вложение». Аналогично работает `Ctrl+V`:
  файлы из буфера вставляются как вложения.
- В чате нажмите `📎` — открывается меню вложений в стиле Telegram:
  «Фото или видео», «Файл», «Музыка», «Голосовое сообщение» и «Видеокружок».
  В Windows диалог выбора показывает все файлы без фильтра по расширениям,
  а вид сообщения определяется автоматически по содержимому (картинка →
  фото, видео/аудио → файл-карточка с плеером). На Android выбор сужается
  MIME-фильтром (фото/видео или аудио).
- **Альбомы** — несколько фото, выбранных за один раз, отправляются одним
  блоком и показываются сеткой 2×2 с подписью «N фото», как в Telegram.
- **Загрузка вложений** — при скачивании фото, видео или файла в пузыре
  показывается полоса прогресса с процентами и объёмом, а кнопка `✕`
  отменяет загрузку.
- **Сохранение на устройство** — кнопка `💾` в просмотрщике фото, в
  полноэкранном плеере и в меню сообщения: на Android фото и видео
  сохраняются в галерею, на ПК — в папку `Pictures\SecureChat`
  (для видео — `Videos`, для аудио — `Music`).
- **Медиа и память** (Настройки → «Медиа и память») — сколько места занято
  локальными копиями вложений и кнопка «Освободить место» (переписка
  остаётся, файлы скачаются заново). Там же режим автозагрузки вложений:
  «Всегда», «По Wi-Fi» или «Никогда» — в режиме «Никогда» крупные файлы
  скачиваются только по нажатию.
- **Вкладка «Медиа и файлы»** в правой панели чата: вложения сгруппированы
  по датам («Сегодня», «Вчера», «12 ноября»), у каждого — иконка по виду
  (фото, видео, голосовое, кружок, аудио, документ) и размер.
- Голосовые сообщения записываются в компактном окне с таймером и кнопками
  «Отмена» / «Отправить», а прослушиваются inline: пауза, перемотка по
  аудиодорожке, текущее время и длительность. На Windows при запрете доступа
  к микрофону приложение предложит открыть настройки системы.
- Изображения отображаются под сообщением; просмотрщик поддерживает
  pinch-to-zoom, панорамирование, двойной тап и свайп вниз для закрытия.
- Анимированные **GIF** проигрываются целиком (кадры идут сами) и в ленте
  чата, и в полноэкранном просмотрщике: отрисовку ведёт системный WebView,
  поскольку MAUI-`Image` показывает только первый кадр. Подложка под GIF —
  цвет пузыря сообщения.
- Видеокружок записывается через системную камеру (на Android — приложение
  камеры, на Windows — приложение «Камера»): видны предпросмотр, таймер и кнопки
  остановки/подтверждения. После подтверждения видео отправляется автоматически.
  Если Windows запрещает доступ к камере или микрофону, приложение предложит
  открыть «Настройки → Конфиденциальность».
- Видео и аудио открываются в полноэкранном плеере со своими настройками:
  пауза, перемотка ±10 с кнопками `⏪⏩` и **двойным кликом по половинам кадра**,
  таймер, **скорость 0,5–2×**, **громкость и звук** (🎤`M`), **повтор** `🔁`,
  «картинка в картинке» 🖼 и полноэкранный режим ⛶. Громкость, скорость и
  повтор запоминаются между открытиями. Клавиши: `Space` — пауза,
  `←/→` — ±5 с, `↑/↓` — громкость, `M` — звук, `L` — повтор.
  Видеокружок воспроизводится по кругу.
- Остальные файлы показывают имя и размер; кнопка «Открыть» сохраняет временную расшифрованную копию в кэш и открывает стандартным приложением ОС. Temporary-файл не удаляется автоматически после закрытия внешнего приложения.
- В списке чатов и уведомлениях вложение отображается как «📷 Фото» или «📎 имя-файла».

## Горячие клавиши (Windows)

| Клавиша | Действие |
|---|---|
| Ctrl+N | Начать новый чат |
| Esc | Закрыть чат |
| Enter | Отправить сообщение |

Размер и позиция окна сохраняются между запусками. Чат сконфигурирован как двухпанельный: слева список переписок, справа выбранный чат. Общее количество непрочитанных сообщений отображается в заголовке окна.

Уведомления о новых сообщениях используют Windows-Toast. Если приложение запущено с повышенными правами (как в среде разработки), системные тосты недоступны — используется встроенный в приложение тост внизу экрана чата. Новое сообщение сопровождается коротким звуком. Звук отключается в настройках («Звук уведомлений»); preview текста включается отдельно. Звук не дублируется системным тостом.

**Рингтон уведомлений.** В «Настройках» рядом с «Звуком уведомлений» выбирается тон: «Системный» (Windows — «Астериск», Android — мелодия уведомлений из настроек ОС) или один из встроенных тонов — «Колокольчик», «Мягкий», «Сигнал», «Пинг». Все встроенные тоны синтезируются скриптом `tools/GenerateRingtones.ps1` и не содержат сторонних материалов. На Windows тон играется ярким снимочным звонком через `winmm.PlaySound`, на Android — через `MediaPlayer` в foreground и как звук канала уведомлений в фоне (при смене тона канал пересоздаётся, поскольку звук канала неизменяем).

На Android системные уведомления показываются, когда приложение в фоне: каждое уведомление привязано к чату (отдельный ID и число непрочитанных), группируется, а нажатие открывает переписку. Для Android 13+ приложение запрашивает разрешение на уведомления после входа. Уведомления и звук можно отключить для отдельного чата через меню ⋮ → «🔇 Без звука».

Чтобы соединение не рвалось свёрнутым приложением, при уходе в фон SecureChat удерживает wake lock и Wi-Fi lock (разрешения `WAKE_LOCK`, `ACCESS_WIFI_STATE`): Android не приостанавливает сеть SignalR, и уведомления продолжают приходить, пока процесс жив. Без этого через пару секунд в фоне удерживаемая сеть засыпала бы, соединение умирало и уведомления прекращались. После системной остановки процесса при возврате приложение переподключается автоматически (цикл реконнекта + мгновенная попытка при возврате на передний план).

## Структура протокола

`EncryptedEnvelope` содержит: id, отправителя, получателя, время, эфемерный
публичный ключ, nonce, ciphertext, tag и подпись. Заголовок и криптополя входят
в подписываемые данные и AAD AES-GCM, поэтому изменение любого поля приводит к
отклонению сообщения.

## Лицензия

Учебный пример. Используйте на свой риск; для реальной переписки необходим
независимый аудит безопасности.
