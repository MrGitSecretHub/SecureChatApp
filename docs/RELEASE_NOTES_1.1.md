# SecureChat 1.1

Защищённый чат для Windows и Android со сквозным шифрованием, собственным
сервером и интерфейсом в стиле Telegram. Версия 1.1 — завершающая волна:
истории, резервная копия ключей, проверка отпечатков, полный TCP-паритет
для пространств, ротация ключей и 11 языков интерфейса.

## Основное

- **Истории (Stories).** Публикация фото и видео с автоудалением через сутки,
  просмотр с индикатором прогресса, ответы и выбор адресата — все контакты
  или конкретное пространство. Истории пространств не смешиваются с личными.
- **Резервная копия ключей.** Экспорт и импорт по паролю в формате `SCKEY1`
  (PBKDF2, 210 000 итераций, AES-256-GCM). Импорт доступен прямо на экране
  входа, поэтому новое устройство восстанавливает ключи до авторизации.
  Кнопка «Проверить бэкап» подтверждает пароль и корректность шифрования.
- **Проверка ключа.** Отпечаток можно скопировать или отправить через другой
  канал. Подтверждение требует ввести случайную группу символов отпечатка —
  простого «доверять» в одно нажатие больше нет.
- **Пространства.** Полная работа по TCP наравне с SignalR: сообщения,
  реакции, закрепления, правка и удаление, участники, приглашения, заявки,
  выдача и ротация ключей. Локальный кэш расшифрованных сообщений сохраняет
  историю офлайн и позволяет искать по ней. Скрытые пространства, индикаторы
  активности, медиа-панель и цветные аватары.
- **Ротация ключа пространства.** Владелец или администратор меняет общий
  ключ; сервер перешифровывает его для всех участников. Новые участники не
  могут прочитать старую историю с сервера, а у существующих она остаётся
  в локальном кэше.
- **Сообщения.** Меню с быстрыми реакциями, единые пустые состояния,
  отложенная отправка по долгому нажатию на ➤, работающая и на Android.
- **Интерфейс.** Двухпанельная страница пространств на ПК, истории первыми
  в сайдбаре, компактные строки, 11 языков (английский по умолчанию).
- **Безопасность транспорта.** HTTPS по умолчанию, fail-closed TOFU и никакого
  автоматического TCP-fallback, который мог бы утечь JWT. Вход по `http://`
  требует явного подтверждения.

## Установка

- **Android:** `SecureChat-v1.1.apk` — установить на устройство. Если стоит
  более ранняя сборка с другой подписью, удалите её перед установкой.
- **Windows:** распаковать `publish\win` и запустить `SecureChat.App.exe`.
- **Сервер:** запускать из каталога `src\SecureChat.Server`, чтобы он нашёл
  `App_Data` и LAN-сертификат. Проверка: `https://localhost:5443/api/health`.

Адрес сервера в Android по умолчанию — `https://10.0.2.2:5443` (эмулятор).
Для физического устройства укажите LAN-IP компьютера по HTTPS.
Подробности — в [README.md](../README.md).

## Известные ограничения

- Фоновые push-уведомления пока не реализованы: нужны FCM или UnifiedPush.
- Нет Double Ratchet и полной forward secrecy при компрометации долговременного
  ключа; ротация ключа пространства защищает только от чтения старой истории
  новыми участниками.
- Сервер — один процесс с SQLite, без кластеризации.
- Метаданные (кто, кому и когда) сервер видит — это свойство relay-модели.
- Проект учебно-демонстрационный и не проходил внешний аудит.
