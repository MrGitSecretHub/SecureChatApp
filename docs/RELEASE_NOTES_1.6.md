# SecureChat 1.6

Версия 1.6: интерфейсные доработки, менеджер памяти, настраиваемый прокси,
статусы в пространствах и исправление публикации сторис.

## Что нового

### Пространства

- Закрепление тем форума и каналов сообщества: ⋯ → 📌, закреплённые разделы
  всегда выше остальных. Синхронизация по SignalR и TCP.
- Статусы доставки для своих сообщений: `◌` → `✓` → `✓✓`, когда другой участник
  просматривает ленту.
- Исправлено переключение в пустые каналы и отображение вложений после
  перезапуска; устранено зависание после закрытия просмотрщика.

### Файлы и память

- Разбивка кэша вложений по чатам и по типам файлов (фото, видео, голосовые,
  документы) с круговой диаграммой, как в Telegram.
- Выборочная и полная очистка кэша.

### Сеть

- Настраиваемый HTTP/SOCKS-прокси для REST и SignalR. Пустое значение означает
  игнорирование системного прокси, как раньше.

### Интерфейс

- Папки чатов: иконки emoji и цвета, счётчики непрочитанных на вкладках.
- Редактор тем: копирование цвета одной роли в другую.
- Поиск по истории: фильтры по автору, типу вложений и периоду.
- Сторис: панель быстрых стикеров; фото уменьшается перед шифрованием,
  что устранило ошибку «Too large» при публикации.

## Установка

- **Android:** `SecureChat-v1.6.apk` — установить поверх предыдущих версий.
  Подпись та же, удалять приложение не нужно.
- **Windows:** распаковать `SecureChat-1.6-win-x64.zip` и запустить `SecureChat.App.exe`.
  Отдельный `exe` без DLL из архива не работает.

Сервер запускать из каталога `src\SecureChat.Server`.
Проверка: `https://localhost:5443/api/health`.
