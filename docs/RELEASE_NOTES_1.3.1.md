# SecureChat 1.3.1

Патч-релиз: удалена временная диагностика, все исправления 1.3 сохранены.

## Что изменилось

- Удалён диагностический лог `securechat-diag.log` и все связанные записи в коде.
- Версия сборки: `1.3.1` (`versionCode=5`).
- Сохранены все исправления 1.3: двухпанельный форум, каналы сообществ,
  каталог сообществ, опросы, корректная локализация и работа вложений
  в пространствах, включая устранение зависания после закрытия просмотрщика.

## Установка

- **Android:** `SecureChat-v1.3.1.apk` — установить поверх 1.3.
  Подпись та же, удалять приложение не нужно.
- **Windows:** распаковать `SecureChat-1.3.1-win.zip` и запустить `SecureChat.App.exe`.
  Отдельный `exe` без DLL из архива не работает.

Сервер запускать из каталога `src\SecureChat.Server`.
Проверка: `https://localhost:5443/api/health`.
