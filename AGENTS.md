# Инструкции проекта SecureChat

## Временные файлы

Все временные/промежуточные файлы (скрипты, логи сборки, дампы, скриншоты,
сгенерированные辅助-файлы) создавать **только внутри каталога проекта**
`D:\VSrepo\NewProject\SecretChatApp`, например в отдельной папке `.tmp`.

Запрещено использовать `C:\Users\Administrator\AppData\Local\Temp` и другие
каталоги на диске `C:` для временных файлов — это засорять диск C:.
Если временный файл нужен только для одной команды, удаляйте его после использования.

Исключение: системные каталоги, куда инструменты пишут логи сами (например,
`C:\Users\Administrator\.local\share\opencode\...`) — их изменять не требуется.
